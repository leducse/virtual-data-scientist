# Deep Analysis Workflow

1. Load the AgentCore handoff context bundle.
2. Inspect the dataset reference, schema profile, light-analysis report, and
   generated code artifact.
3. Restate the user's decision goal and the likely analysis type.
4. Run only the techniques justified by the data shape and user goal.
5. Check leakage, target quality, validation split, metric choice, and sample
   size before reporting model results.
6. Store all code, metrics, charts, and narrative conclusions as artifacts.
7. End with what the result supports, what it does not support, and what data to
   collect next.
